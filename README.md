# Gouthamdas K — Personal Portfolio

Minimal one-page personal website for GitHub Pages.

## Repository structure

Upload these files directly to the repository root:

- `index.html`
- `style.css`
- `script.js`
- `.nojekyll`
- `logo.png`
- `profilephoto.png`
- `favicon.png`
- `Gouthamresume.pdf`

Keeping the images in the repository root avoids broken relative paths when uploading through GitHub's web interface.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

Expected URL:

https://gouthu28.github.io/gouthamportifolio/
