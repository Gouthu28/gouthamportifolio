# Gouthamdas K — Personal Portfolio

Minimal one-page personal website designed for QR-code access and GitHub Pages.

## Files

- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — WhatsApp link handling
- `assets/profilephoto.png` — profile image
- `assets/logo.png` — black transparent logo
- `assets/favicon.png` — favicon

## Before publishing

1. Upload `Gouthamresume.pdf` to the repository root.
2. Commit the changes.
3. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
